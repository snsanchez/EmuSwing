=======
Emulador sencillo para juegos clásicos y arcade hecha con **Java Swing**.
La idea es ofrecer una forma simple de acceder a juegos como **Doom, Prince of Persia o Street Fighter II**, sin requerir de conocimientos extra, sin piratería y sin exponerse a malware.

El proyecto está pensado alrededor de un sistema de **suscripción mensual**, desde el cual el usuario puede acceder al catálogo disponible.

## Tecnologías
* Java 8
* Java Swing
* Eclipse
* Arquitectura MVC

## Estructura

El proyecto está separado en módulos para mantener cada parte organizada:

* **ENTITIES** — modelos y entidades del sistema.
* **COMMONS** — clases y elementos compartidos.
* **FRONTEND** — interfaz gráfica y lógica relacionada con Swing.
* **BACKEND** — acceso a datos y lógica del sistema.
